# DeGPT Web UI

DeGPT的可视化Web界面，提供友好的用户交互体验。

## 功能特性

- 🎨 现代化的用户界面
- 📝 代码输入和编辑
- 🔄 多种优化选项（简化、注释、重命名、全部）
- 📊 优化结果对比显示
- 📋 一键复制优化结果
- ⚡ 实时配置检查

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行应用

在`DeGPT/web_ui`目录下运行：

```bash
python app.py
```

然后在浏览器中访问：`http://localhost:5000`

## 使用说明

1. **检查配置**：页面加载时会自动检查LLM配置状态
2. **输入代码**：在代码输入框中粘贴或输入反编译的C代码
3. **选择优化类型**：
   - 全部优化：执行所有优化步骤
   - 简化代码：仅简化代码结构
   - 添加注释：仅添加代码注释
   - 重命名变量：仅重命名变量
4. **开始优化**：点击"开始优化"按钮，等待处理完成
5. **查看结果**：在结果区域查看原始代码和优化后的代码对比

## 快捷键

- `Tab`：在代码输入框中插入4个空格
- `Ctrl + Enter`：快速执行优化

## 注意事项

- 确保已正确配置LLM API密钥（在`degpt/config.ini`中）
- 优化过程可能需要一些时间，请耐心等待
- 如果遇到错误，请查看浏览器控制台和服务器日志
